# 简易博客系统

这是一个使用Python和Flask框架开发的简易博客系统，采用JSON文件进行数据持久化存储。

## 功能特点

- 用户注册和登录
- 文章的创建、查看、编辑和删除
- 响应式设计，适配不同设备
- 简洁美观的用户界面
- 使用JSON文件存储数据，无需数据库

## 技术栈

- **后端**：Python + Flask
- **前端**：HTML + CSS + JavaScript + Bootstrap 5
- **数据存储**：JSON文件

## 目录结构

```
.
├── blog.py            # 主应用文件
├── data/              # 数据存储目录
│   ├── posts.json     # 文章数据
│   └── users.json     # 用户数据
├── static/            # 静态资源
│   ├── css/           # CSS样式
│   │   └── style.css  # 自定义样式
│   └── js/            # JavaScript脚本
│       └── main.js    # 自定义脚本
└── templates/         # HTML模板
    ├── edit_post.html # 编辑文章页面
    ├── index.html     # 首页
    ├── layout.html    # 基础布局
    ├── login.html     # 登录页面
    ├── new_post.html  # 新建文章页面
    ├── post.html      # 文章详情页面
    └── register.html  # 注册页面
```

## 安装和运行

### 前提条件

- Python 3.6 或更高版本
- pip（Python包管理器）

### 安装步骤

1. 克隆或下载本项目到本地

2. 安装所需依赖包
   ```
   pip install flask
   ```

3. 运行应用
   ```
   python blog.py
   ```

4. 在浏览器中访问 `http://127.0.0.1:5000` 即可使用博客系统

## 使用说明

1. 首次使用需要注册账号
2. 登录后可以创建、编辑和删除自己的文章
3. 未登录用户只能浏览文章

## 数据存储

所有数据都存储在 `data` 目录下的JSON文件中：
- `posts.json`：存储所有博客文章
- `users.json`：存储用户信息

## 注意事项

- 本项目仅用于学习和演示目的
- 实际生产环境中应考虑使用数据库进行数据存储
- 密码存储采用明文方式，实际应用中应使用加密存储
